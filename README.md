# Basic Sign Language Translator

ต้นแบบเว็บแอปรู้จำคำหรือวลีภาษามือพื้นฐานจากกล้องเว็บแคม ใช้ MediaPipe Hands สกัดจุดสำคัญมือซ้ายและขวา 21 จุดต่อมือ แล้วส่งลำดับ 30 เฟรมเข้า LSTM หรือ BiLSTM หน้าเว็บแสดงข้อความภาษาไทยและสถานะเมื่อยังไม่มั่นใจ

โครงงานนี้เป็นระบบจำแนกเฉพาะคลาสที่เก็บข้อมูลและฝึกไว้ ไม่ใช่ระบบแปลภาษามือไทยทั้งหมด และยังไม่รองรับบทสนทนาอิสระ

## ติดตั้ง

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## 1. เก็บข้อมูล

เก็บข้อมูลให้ครบทุกคลาสและให้แต่ละผู้ทำท่าแสดงทุกคลาส ตัวอย่าง:

```powershell
python collect_data.py --label HELLO --text "สวัสดี" --subject S01 --samples 40
python collect_data.py --label NEED_HELP --text "ขอความช่วยเหลือ" --subject S01 --samples 40
```

ทำซ้ำสำหรับผู้ทำท่าคนอื่น โดยใช้ `--subject` คนละรหัส ตัวอย่างใน PDF ระบุให้บันทึกผู้ทำท่าหลายคน; โค้ดแนะนำอย่างน้อย 5 คน และต้องมีอย่างน้อย 3 คนเพื่อแยก train/validation/test ตามบุคคล กด `SPACE` เพื่อบันทึกหนึ่งลำดับ และ `Q` เพื่อออก

ไฟล์ข้อมูล `data/sequences.npz` เก็บ `X` (ลำดับจุดสำคัญ), `y` (รหัสคลาส), `texts` (ข้อความภาษาไทย) และ `subjects` (ผู้ทำท่า) ขอความยินยอมและจำกัดการเข้าถึงข้อมูลผู้เข้าร่วมตามแนวทางในเค้าโครง

## 2. ฝึกและประเมิน

```powershell
python train.py --model lstm
python train.py --model bilstm
```

สคริปต์แยกผู้ทำท่าออกเป็น train, validation และ test คนละกลุ่ม หากชุดข้อมูลไม่สามารถใส่ทุกคลาสลงในทั้งสามกลุ่มได้ จะหยุดและแจ้งให้เพิ่มข้อมูล ผลและโมเดลอยู่ใน `models/` โดยรายงาน Accuracy, macro Precision/Recall/F1, classification report, confusion matrix และเวลา inference ของโมเดลต่อ sequence. เวลาแสดงในหน้าเว็บรวมเวลารับส่งภาพและประมวลผลแต่ละเฟรม ซึ่งเป็นค่าคนละขอบเขตกับเวลา inference ในรายงาน

## 3. เปิดโหมดสาธิตสำหรับนำเสนอ

ยังไม่มีชุดข้อมูลหรือโมเดลก็เปิดหน้าจอเพื่อนำเสนอ flow ได้ ติดตั้ง Flask อย่างเดียวก็พอสำหรับโหมดนี้:

```powershell
pip install Flask
python app.py --demo
```

เปิด `http://127.0.0.1:5000` แล้วกดปุ่มตัวอย่าง เช่น “สวัสดี” หรือ “ขอความช่วยเหลือ” เพื่อแสดงผลบนหน้าเว็บ โหมดนี้เป็นเพียงตัวอย่าง UI และข้อความจำลอง ไม่ได้ตรวจจับมือ ไม่ได้รู้จำท่าจริง และไม่ควรนำผลไปอ้างเป็นผลทดลอง การเปิดกล้องในโหมดนี้มีไว้แสดงส่วนติดต่อเท่านั้น

## 4. เปิดเว็บแอปที่ใช้โมเดล

```powershell
python app.py
```

เปิด `http://127.0.0.1:5000` แล้วกด “เปิดกล้อง” และอนุญาตสิทธิ์กล้อง หน้าเว็บส่งภาพเฟรมไปยัง Flask บนเครื่องเดียวกันเพื่อสกัดจุดและจำแนก กด “หยุดกล้อง” เพื่อจบการใช้งาน เปลี่ยน host/port/threshold ได้ เช่น:

```powershell
python app.py --host 127.0.0.1 --port 5000 --threshold 0.70
```

เมื่อเปิดให้เข้าจากเครื่องอื่น การอนุญาตกล้องของ browser อาจต้องใช้ HTTPS และต้องประเมินความปลอดภัย/ความเป็นส่วนตัวก่อนนำไปใช้งานจริง

## รูปแบบและขอบเขตการทดลอง

- หนึ่งเฟรมแทนพิกัด `(x, y, z)` ของมือซ้ายและขวา รวม 126 คุณลักษณะ
- หนึ่งตัวอย่างเป็นลำดับคงที่ 30 เฟรม; เมื่อไม่พบมือทั้งสองข้างจะใช้ค่าจากเฟรมก่อนหน้า
- LSTM และ BiLSTM ใช้ข้อมูลชุดเดียวกัน; BiLSTM ต้องรอให้มีลำดับครบก่อนทำนาย
- แบ่งชุดข้อมูลโดย `subject ID` ทั้ง train/validation/test เพื่อหลีกเลี่ยงข้อมูลผู้ทำท่าคนเดียวกันรั่วข้ามชุด
- วัดเวลาตอบสนองบนหน้าเว็บจากเริ่มส่งเฟรมจนได้รับผลกลับ ส่วนรายงานฝึกแยกเวลา inference ของโมเดล
- ความเชื่อมั่นต่ำกว่า threshold จะแสดงสถานะ “ไม่พบคำที่มั่นใจ”
- ควรให้ผู้รู้ภาษามือตรวจสอบความถูกต้องและความเป็นธรรมชาติของคำ/วลีก่อนบันทึกและสรุปผล

## ไฟล์หลัก

- `sign_utils.py` — MediaPipe, สกัด landmark และเก็บลำดับเฟรม
- `collect_data.py` — เก็บลำดับพร้อม label, ข้อความภาษาไทย และ subject ID
- `train.py` — ฝึก LSTM/BiLSTM และประเมินด้วยการแบ่งชุดตามผู้ทำท่า
- `app.py` — Flask API และการทำนายจากกล้อง
- `templates/index.html` — หน้าเว็บเปิดกล้องและแสดงผลภาษาไทย
